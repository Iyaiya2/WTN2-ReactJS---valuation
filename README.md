# Ma Collection de Plantes

## Objectif du projet
Ce projet permet aux utilisateurs de gérer et d'afficher une collection de plantes, en ajoutant des informations et en visualisant des détails sur chaque plante. 

## Fonctionnalités
- Ajouter des plantes avec leur nom, espèce et description.
- Afficher une liste de plantes ajoutées.
- Voir les détails d'une plante spécifique.
- Basculer entre les modes clair et sombre.

## Prérequis
Assurez-vous d'avoir les éléments suivants installés sur votre machine :
- Node.js 
- npm
